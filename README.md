# Консольный калькулятор

Небольшой калькулятор на Python для выполнения основных арифметических операций над двумя целыми числами.

## Возможности

- сложение (`+`);
- вычитание (`-`);
- умножение (`*`);
- деление (`/`);
- проверка деления на ноль.

## Запуск

Убедитесь, что установлен Python 3, затем выполните в корневой папке проекта:

```bash
python3 p1_calculator.py
```

Программа последовательно запросит первое число, арифметическую операцию и второе число. Введите операцию одним из символов `+`, `-`, `*` или `/`.
