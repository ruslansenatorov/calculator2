# Учебный проект
Simple CLI Calculator
Минималистичный калькулятор на Python с проверкой типов и линтерами.

✨ Особенности
Типизация: Код полностью аннотирован и проверен через mypy.

Качество: Соответствует стандартам PEP 8 (проверено pylint и black).

Безопасность: Обработка деления на ноль и некорректного ввода.

🚀 Быстрый старт
Запуск:

Bash
python p1_calculator.py
Проверка линтерами:

Bash
pre-commit run --all-files
