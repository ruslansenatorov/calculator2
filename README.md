# Calculator2

Небольшой учебный консольный калькулятор на Python. Проект показывает базовую работу с пользовательским вводом, условными операторами и арифметическими операциями.

## Возможности

- Ввод двух чисел через консоль.
- Выбор арифметической операции.
- Поддержка операций:
  - сложение `+`
  - вычитание `-`
  - умножение `*`
  - деление `/`
- Обработка деления на ноль.
- Сообщение об ошибке при неизвестной операции.

## Структура проекта

```text
.
```

## Требования

- Python 3.9 или новее.

Внешние библиотеки для запуска калькулятора не требуются.

## Запуск

Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <URL-репозитория>
cd calculator2
```

Запустите программу:

```bash
python p1_calculator.py
```

После запуска программа последовательно попросит:

1. Ввести первое число.
2. Ввести арифметическую операцию.
3. Ввести второе число.

Пример сценария:

```text
enter your first number10
enter  arithmetic operation  like +,-,*,/+
enter your  second number5
the sum of 10 + 5 are 15
```

## Важное замечание

В текущей версии в `p1_calculator.py` операция считывается через `int(input(...))`, хотя дальше сравнивается со строками `"+"`, `"-"`, `"*"`, `"/"`. Чтобы программа корректно принимала символы операций, ввод операции нужно читать как строку:

```python
operation = input("enter arithmetic operation like +,-,*,/")
```

## Проверка качества кода

В проекте есть конфигурация `.pre-commit-config.yaml` с хуками для форматирования и статической проверки, включая `black`, `isort`, `flake8`, `mypy`, `pylint`, `pyupgrade`, `codespell` и инструменты для Jupyter Notebook.

Чтобы использовать проверки локально:

```bash
pip install pre-commit
pre-commit install
pre-commit run --all-files
```
