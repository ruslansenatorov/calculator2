# Simple Calculator

Консольный калькулятор на Python, выполняющий базовые арифметические операции: сложение, вычитание, умножение и деление.

## Возможности

- Сложение (`+`)
- Вычитание (`-`)
- Умножение (`*`)
- Деление (`/`) с проверкой деления на ноль

## Требования

- Python 3.x

Дополнительные зависимости не требуются — используется только стандартная библиотека Python.

## Установка

```bash
git clone https://github.com/Dockstage/calculator2.git
cd calculator2
```

## Использование

Запусти скрипт:

```bash
python calculator.py
```

Программа последовательно запросит:
1. Первое число
2. Арифметическую операцию (`+`, `-`, `*`, `/`)
3. Второе число

И выведет результат вычисления.

### Пример работы

```
enter your first number: 10
enter arithmetic operation like +,-,*,/: +
enter your second number: 5
the sum of 10 + 5 are 15
```

## Обработка ошибок

- При попытке деления на ноль программа выводит предупреждающее сообщение вместо аварийного завершения
- При вводе неподдерживаемой операции выводится сообщение об ошибке
